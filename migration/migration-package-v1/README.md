Reproduce and verify from the repository root:

```text
cargo run --locked -p mcloving-migration-package -- generate .
cargo run --locked -p mcloving-migration-package -- verify \
  migration/migration-package-v1/migration-package.json .
```

The generated bytes must match `migration-package.json` exactly and its
SHA-256 must match both `SHA256SUMS` and the digest compiled into the
verifier.

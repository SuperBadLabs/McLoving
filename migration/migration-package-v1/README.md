# MIG-007 migration package v1

This directory contains the deterministic review package for the sole
MIG-006-certified corpus case, `corpus-052-cinqict_jenkinsdev`. The source and
imported operational state are disabled. The package grants no trigger,
scheduler, credential, runner, connector, effect, canary, cutover, rollback,
or decommission authority.

The canonical JSON envelope embeds the exact source export, compiler response,
strict pipeline YAML, `JOBSTATE-001` import YAML, compiler trace, mapping
catalog and lock, full 228-case corpus disposition ledger, MIG-006 aggregate,
and DIFF-002 state-policy receipt. It binds the reviewed v0.1.0 release
envelope/evidence/verification digests and the exact MIG-005A
transform/manifests/bundles plus its four accepted rehearsal receipt digests.
The admitted job has zero persistent state dependencies, so the case-specific
state-rehearsal set is explicitly empty rather than borrowing the synthetic
MIG-005A fixture.

Reproduce and verify from the repository root:

```text
cargo run --locked -p mcloving-migration-package -- generate .
cargo run --locked -p mcloving-migration-package -- verify \
  migration/migration-package-v1/migration-package.json .
```

The generated bytes must match `migration-package.json` exactly and its
SHA-256 must match both `SHA256SUMS` and the digest compiled into the
verifier.
